## How to navigate

- **The file explorer**, on the left, to move around with your mouse.
- **The terminal**, below: open it with `CTRL + Ñ` and start with `ls`.

Both views show the same content. Use whichever you find more comfortable.

## Where to start

```bash
cd proyectos     # my projects, one per folder
ls               # see what's there
cat README.md    # read the one you're interested in
```

Each project has its own README: the problem it solved, how I solved it, and the technologies I used.

## Ask me

There's an assistant connected to all this content. It's not a chatbot pasted on top: it reads the same documents you're navigating.

```bash
ai what projects has Brian worked on?
ai tell me about the hardest one
```

You can also type `ai` by itself to enter conversation mode.

## Commands

| Command | What it does |
|---------|--------------|
| `ls` | List files and folders |
| `cd [folder]` | Enter a folder (`cd ..` to go back) |
| `cat [file]` | Read a file |
| `tree` | See the full structure |
| `theme` | Change the visual theme |
| `lang` | Change the interface language |
| `help` | See every command |

For the complete list: `cat COMANDOS.md`.
