## Cómo navegarlo

- **El explorador de archivos**, a la izquierda, para moverte con el mouse.
- **La terminal**, abajo: abrila con `CTRL + Ñ` (o `Ctrl + K`) y empezá por `ls`.

Las dos vistas muestran lo mismo. Usá la que te resulte más cómoda.

## Por dónde empezar

```bash
cd proyectos     # mis proyectos, uno por carpeta
ls               # ver qué hay
cat README.md    # leer el que te interese
```

Cada proyecto tiene su propio README con el problema que resolvía, cómo lo resolví y con qué.

## Preguntame

Hay un asistente conectado a todo este contenido. No es un chatbot pegado encima: lee los mismos documentos que estás navegando.

```bash
ai ¿en qué proyectos trabajaste?
ai contame del que más te costó
```

También podés escribir `ai` a secas para entrar en modo conversación.

## Comandos

| Comando | Qué hace |
|---------|----------|
| `ls` | Listar archivos y carpetas |
| `cd [carpeta]` | Entrar a una carpeta (`cd ..` para volver) |
| `cat [archivo]` | Leer un archivo |
| `tree` | Ver la estructura completa |
| `theme` | Cambiar el tema visual |
| `lang` | Cambiar el idioma de la interfaz |
| `help` | Ver todo |

Para la lista completa: `cat COMANDOS.md`.
